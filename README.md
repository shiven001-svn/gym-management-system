# Gym Management System

A Python-based Gym Management System developed using Object-Oriented Programming (OOP).

## Features
- Member management
- Trainer management and assignment
- Membership plan management
- Payment tracking
- Dashboard with summary statistics
- Data storage using CSV files
- Data visualization using Matplotlib

## Technologies Used
- Python
- Object-Oriented Programming (OOP)
- CSV for data persistence
- Matplotlib for charts

## How to Run
1. Install Python 3.
2. Install Matplotlib:
   `pip install matplotlib`
3. Run the program:
   `python gym_management_dashboard.py`

## Data Storage
The system stores member, trainer, membership plan, and payment records in CSV files.

## Project Purpose
This project demonstrates the use of Python OOP concepts, file handling, data management, and visualization in a gym management application.
